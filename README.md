# MoneyMind — AI家計簿アシスタント

AI 機能付きの家計簿 Web アプリです。支出の管理に加え、自然言語入力と RAG チャットで家計の振り返りをサポートします。

## 機能

### 支出管理
- 支出の登録・一覧・編集・削除
- カテゴリ（食費・交通・娯楽・日用品・医療・その他）での分類
- 金額・日付・メモの入力

### 月次サマリー・グラフ
- 今月の合計金額と前月比較の表示
- カテゴリ別の円グラフ（月ごとに切り替え可能）
- グラフの各カテゴリをクリックすると、その月の内訳一覧を表示

### 支出一覧
- 月ごとの一覧表示（前後の月へ切り替え可能）
- カテゴリ別の合計・件数から内訳モーダルを開ける
- 一覧のカテゴリバッジからも同じ内訳を表示

### 自然言語入力
- 「ランチ500円」のような短い文章から、金額・カテゴリ・日付・メモを自動抽出
- AI（Gemini / OpenAI）の Function Calling で仕訳
- API キーがない場合はルールベース解析で動作

### RAG チャット
- 「今月なぜ食費が増えた？」など、登録データに基づく質問に回答
- 関連する支出を検索し、根拠付きで返答
- 回答に使った支出データの引用元を画面上に表示

### AI プロバイダー切り替え
- Gemini / OpenAI / 無料モード（ルールベース）に対応
- 利用制限やエラー時は、別モデル・別手段へ自動フォールバック
- API キーなしでも基本的な AI 機能を利用可能
